JRPay (kunde)

Dette er en utviklingsplaceholder som serveres av nginx på port 5173. Faktisk Client Web (Fase 4 av GUI-initiativet) erstatter denne siden med en React SPA koblet til Fase-2 kundeendepunktene.

Hva som er klart (Fase 2)

  • Identity — http://identity:8097 (OAuth2 + SCA, BankID-simulert)
  • A4 PSD2 / kontoer + betalinger — /api/v1/customer/accounts/*, /api/v1/customer/payments/* på port 8094
  • A3 Bill Payment / R2P + AvtaleGiro + favoritter — /api/v1/customer/r2p/*, /mandates/*, /beneficiaries/* på port 8093
  • Notifications — /api/v1/customer/notifications/* på port 8098

OAuth2 callback for kommende SPA er http://localhost:5173/oauth/callback.

Bygget fra implementation/docker/client-web/.
