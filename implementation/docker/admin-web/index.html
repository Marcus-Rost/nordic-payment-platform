JRPay Admin Console

This is a development-time placeholder served by nginx on port 5174. The real Admin Web (Phase 3 of the GUI initiative) replaces this static page with a React SPA backed by the Phase-2 admin endpoints.

What's wired today (Phase 2)

  • Identity — http://identity:8097 (OAuth2 Authorization Server, SCA, password reset, privacy notice)
  • A1 Account Ledger admin — /api/v1/admin/accounts/* on port 8091
  • A5 Fraud + Sanctions admin — /api/v1/admin/fraud/*, /api/v1/admin/sanctions/* on port 8095
  • Audit Query — /api/v1/admin/audit/* on port 8099

The OAuth2 callback configured for the future SPA is http://localhost:5174/oauth/callback.
